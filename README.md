
# DTS Quant Bot

## Overview
DTS Quant Bot is a quantitative trading research project.

## Objectives
- Analyze historical market data.
- Test quantitative and machine-learning strategies.
- Evaluate strategies using backtesting.
- Record research results and performance metrics.

## Safety Rules
- Research and paper trading only.
- Maximum planned risk: 1% per trade.
- No live order execution.

## Development Status
Phase 1: Risk controls and testing.
Phase 2: Historical data engine.
